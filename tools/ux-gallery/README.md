# HA Dial UX Atlas

From the repository root, run:

```sh
python3 tools/ux-gallery/server.py
```

Then open <http://127.0.0.1:4173/tools/ux-gallery/>.

The gallery is a searchable contact sheet. Set the Dial host if needed, then click
any Dial preview to render its 240 × 240 scene and push it to the device. Every concept has a stable ID
that can be quoted in design discussions, for example `NAV-ROLODEX-EMBER` or
`CHR-TRICOMPAX-ALLOY`.
